## 확정 사항 (원장 발화 그대로)

1. **레이더 차트를 «영역별 성취도» 섹션에 통합** — 막대그래프 오른쪽에 컴팩트하게. 강점/보완 칩·평균·영역 등급 표기는 유지.
2. **도넛에 점수 + 등급 동시 표기** — 중앙 "70 /100" 아래에 등급 필(크림 바탕 + 얇은 골드 테두리 + 딥그린/골드 글자, DESIGN.md 골드 규칙 준수). 캡션 "종합 점수 · 등급".
3. **레이더가 있던 자리 → 45문항 답안 지도** — 도넛 오른쪽. 영역별 행(듣기 1–12 / 어휘 13–20 / 문법 21–31 / 독해 32–45), 행 라벨에 "듣기 12/12" 정답수.
   - 정답 칸: 옅은 크림그레이 `#F0EDE1`, 작은 번호 + ✓ (시각적으로 물러남)
   - 오답 칸: `#F9E3D8` + 테두리 `#EDC0A9`, 번호(진갈색 `#993C1D`) + **정답 원문자**(`#B23A2C`) — 학생에게 반환된 시험지와 대조해 복습하는 용도
   - 3점 변별 문항: `inset 0 0 0 1.5px #C9A227` 금테
   - 범례: 정답 / 오답(숫자=정답) / 3점 변별 문항
4. **진단 박스 문장 확장** — 기존 자동 진단 문장 뒤에 약점 유형 문장 자동 생성:
   "특히 문법은 규칙 적용 문항(23·26·28·30·31), 독해는 빈칸·순서 등 논리 연결 유형(37·40·41)에서 감점되어, 반환된 시험지의 붉은 칸 번호를 우선 복습하기를 권합니다."
   → 오답을 유형표로 묶어 영역별 상위 1~2개 유형 + 번호 나열. 오답 중 3점 비중이 높으면 "기본기는 탄탄, 상위 유형에서 감점" 식 해석 한 구절.
5. **총점 표기 불일치 수정(버그)** — 현재 도넛/점수표의 총점이 영역 성취율 단순평균(`ltAvgNum`, 예: 72)이고 진단 문장은 배점 기준 실제 점수(70). **실제 점수로 통일**할 것. 실제 점수 = Σ(맞은 문항 배점), p3 목록은 `_ltOmrKeys()`의 `p3`.
6. **수기 입력(문항 데이터 없는) 학생 분기** — 답안 지도를 만들 수 없으면 **기존 레이아웃(레이더 포함) 그대로** 유지. 조건: 아래 데이터 소스에서 `sub.answers`가 없거나 10문항 미만.

## 구현 시 주의 (이 저장소 함정들 — CLAUDE.md 상세)

- 페이로드는 JSON 한 줄: json.loads → 문자열 치환 → json.dumps(...).replace('</','<\\/') 재인코딩, `</script` 0개 assert
- 캡처카드(#…cap) 안 div 짝 맞춤 필수 — 잉여 `</div>`는 캡처 조기닫힘 사고(v32.578) 재발
- rv는 반드시 해당 통지서를 렌더하는 rv 객체에 추가(엉뚱한 rv에 넣으면 무동작 바인딩)
- sc-for 안 동적 sc-if 버튼 금지 규칙 등 v619 함정 — 이 작업은 표시 전용이라 버튼 없음
